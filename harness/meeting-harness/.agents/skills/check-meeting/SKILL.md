# 회의록 추출기 검증

앱 코드와 테스트를 수정하지 말고 아래 절차로 검증합니다.

1. `requirements.md`를 읽고 요구사항을 기준으로 삼습니다.
2. `python3 -m unittest discover -s tests -v`를 실제 실행합니다.
3. `python3 demo.py`를 실제 실행합니다.
4. 각 검사의 명령, 종료 코드, 출력 요약, 실패 원인(실패가 없으면 `없음`)을 `workspace/checks.txt`에 기록합니다. 요구사항 확인도 체크 단계의 판정 근거로 기록합니다.
5. 각 단계와 전체 결과를 `통과`, `실패`, `미실행` 중 하나로 판정합니다. 실행하지 않은 검사는 성공이나 통과로 기록하지 않습니다. 한 검사라도 실패하면 해당 실패를 기록하고 전체 결과도 실패로 표시합니다. 필요한 실행이나 요구사항 확인이 빠졌으면 전체 결과를 미실행으로 표시합니다.

## 기록 누적

반복 실행할 때 `workspace/checks.txt`의 기존 내용을 보존합니다. 새 검증 묶음은 다음 실행 번호를 붙여 파일 끝에 추가합니다(예: `실행 1`, `실행 2`). 명령별로 명령, 종료 코드, 출력 요약, 실패 원인, 판정을 빠짐없이 남깁니다. 아직 실행하지 않은 명령은 종료 코드와 출력 요약을 `미실행`으로, 실패 원인을 미실행 사유로 기록합니다.
