# 회의록 추출기 검사 기록

## 실행 1

- 요구사항 확인: `requirements.md` 읽음. **통과** — 빈 입력, 줄/내용 양끝 공백 제거, 빈 작업 제외, 순서 및 작업 내부 콜론 보존, 함수명·리스트 반환 조건을 확인.
- 명령: `python3 -m unittest discover -s tests -v`
  - 종료 코드: `0`
  - 출력 요약: 8개 테스트 실행, 모두 통과(`OK`).
  - 실패 원인: 없음.
  - 판정: **통과** (실제 실행함)
- 명령: `python3 demo.py`
  - 종료 코드: `0`
  - 출력 요약: 빈 회의록 `[]`; 샘플에서 `자료 조사`, `슬라이드 작성` 출력.
  - 실패 원인: 없음.
  - 판정: **통과** (실제 실행함)
- 전체 판정: **통과**
