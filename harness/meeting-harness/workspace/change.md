# 작성 변경 기록

## 수정 전 문제

- 빈 문자열과 공백뿐인 입력에서 `ValueError`가 발생해 요구사항 1을 만족하지 않았습니다.
- 줄 앞뒤 공백을 제거하지 않아 공백으로 시작하는 `할 일:` 줄을 놓쳤습니다(요구사항 2).
- 작업 내용의 공백을 제거하지 않았고, 공백뿐인 작업도 결과에 포함했습니다(요구사항 3, 4).

## 수정 내용

- 입력의 각 줄을 양끝 공백 제거 후 확인하고, `할 일:` 접두사가 있는 줄만 처리하도록 변경했습니다.
- 첫 콜론 뒤 내용을 양끝 공백 제거 후 비어 있지 않을 때만 결과에 추가합니다.
- 입력 순서와 작업 내용 내부의 콜론은 유지합니다. 빈 입력도 빈 리스트를 반환합니다.
